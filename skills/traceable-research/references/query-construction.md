# 检索式构造：中文主题如何变成可用的英文检索式

## 为什么需要这一层

中文词直接喂英文库会返回「水母幼虫」「leisure level」这类无关内容。
程序的做法是：领域术语表命中 → 直接用词典等价映射（不经 LLM）；
未命中 → LLM 转换国际期刊通用术语，再经幻觉词校验。

## 构造规则（2026-10-12 修复，务必遵守）

```
对象 ⊕ 条件 → 组合查询（隐含 AND）
条件角色：取全部等价词（不只第一个）
对象角色：cap 3
任务角色：cap 1
兜底：对象单独检索一条（对象型主题靠它广召回，含缩写）
```

修复前的实现**每角色只取首个等价词**，且条件与对象从不组合。后果：
「高水位」的首个等价词恰是字面直译 `high water level`，于是
`sewer network high water level` 召回了潮位、沼泽、地衣、放射性废物、词典条目——
55 条里大半是噪声。修复后同一主题 91 条，主体回到排水管网压力流水力学。

正确输出示例：
```
["sewer network high water level", "sewer network full pipe flow",
 "sewer network surcharge", "sewer network"]
```

## 三层主题理解

```
领域词典命中 → 直接用（对象=排水管网｜条件=高水位）
    ↓ 未命中
LLM 概念解析 → 对象/条件/任务
    ↓ LLM 不可用
规则回退（整词原样送给知网）
```

知网侧还有降级阶梯：完整式 → 去修饰 → 仅对象 → 整词 TKA。
0 命中时按阶梯重试，避免因检索式过严而误判「无文献」。

## 用户该怎么写主题

**推荐中英混写**，一次覆盖两类文献：

```bash
--topic "城镇污水处理 侧流 生物除磷 side-stream EBPR"
```

- 纯中文也可以（程序会转英文检索式），但英文检索质量明显更高：
  免费英文库（S2 / OpenAlex）能命中 Water Research、ES&T 等顶级期刊
- 想只要高质量文献时，直接用英文检索词
- 用**专业术语**而非口语（「城镇排水管道检测与修复」而非「查水管」）

## 召回跑偏时的排查顺序

1. 看 stdout 的 `语义拆解：对象=…｜条件=…｜任务=…` —— 拆错了后面全错
2. 看 `英文检索式` 那一行 —— 是否出现字面直译（high water level 这类）
3. 看 `质量过滤明细` —— 是「主题不相关」还是「非北大核心期刊」
4. 若拆解明显不对，换术语或直接在领域词典里补词（比改代码快）

## 幻觉词风险

LLM 生成的检索式会引入臆造词（实测出现过 `"leisure level"`）。
程序已加幻觉词校验 + 结果相关性过滤，但**仍要人工看一眼检索式本身**——
它决定了后面所有召回的上限。
