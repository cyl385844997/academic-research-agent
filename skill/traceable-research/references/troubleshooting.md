# 故障速查

## 检索类

| 症状 | 原因 | 处理 |
|---|---|---|
| 中文文献全部被剔除 | 免费库中文以灌水刊为主 | 换检索词（用核心刊常见术语）；或走下方「人工补检知网」 |
| 中文剔除但 stdout 没提示 | 已修（2026-09-13）；若复现说明代码回退 | 查 `assess_quality()` 的 `warn_lines` 是否被删 |
| 英文召回大量跑偏文献 | 检索式出现字面直译或多词未组合 | 查 `英文检索式` 那一行；必要时往领域词典补等价词 |
| S2 返回 429 / OpenAlex 503 | 免费源同 IP 高频调用被限流 | 不要反复轰炸单一源；配 `SEMANTIC_SCHOLAR_API_KEY` |
| 三个英文源全失败 | 网络或源侧故障 | 如实报告失败原因（程序不会编造）；稍后重试或缩短关键词 |
| 知网 0 命中 | 检索式过严 | 程序已按阶梯降级重试；仍为 0 则改用专业术语 |

## 人工补检知网（中文核心刊的正式流程）

知网/万方/维普是付费订阅库，**无公开检索 API 且禁止爬虫**，本项目不做自动抓取。
需要补检时：

1. 用**专业术语**而非口语表述
2. 限定近 5 年，勾选「北大核心 / CSSCI」
3. 按「被引」或「相关度」排序，优先高影响力
4. 把找到的记录按 TSV 列序手工补进 `reports/literature_references.tsv`：
   `标题⇥年份⇥作者⇥DOI⇥期刊⇥被引⇥语种`
5. 补完后重跑产物核验，确认白名单与报告一致

## 生成类

| 症状 | 原因 | 处理 |
|---|---|---|
| Crew 卡住不动 | LLM 端点慢（实测单次响应可达 18-19 秒） | 正常等待；两角色约 100 秒，三角色更久 |
| LLM 报 function calling 不支持 | 端点不兼容工具调用 | 换端点；`curl <BASE_URL>/models` 查支持模型 |
| 报告里出现 `〔DOI 不可溯源，已剔除〕` | 闸口拦下编造引用 | 正常防护。核验脚本会退 2（需人工复核），逐条确认后再用 |
| 报告含「检索…返回0条」 | 无工具角色扮演式检索（市场线已知缺陷） | 该断言无效，不得引用；修法见 `guardrails.md` |
| 报告里混入思考标签（`<think>`、`<\|mask_start\|>`） | 模型输出未清洗 | 产物不可直接交付，需重跑或手工清理 |

## 核验类

| 退出码 | 含义 | 处理 |
|---|---|---|
| 0 | 通过 | 可交付 |
| 1 | 存在白名单外引用 | **必须修**。核对该引用是否来自未纳入白名单的检索（缓存与报告不同步时会出现），确认后重跑检索或删除该引用 |
| 2 | 需人工复核 | 产物含闸口剔除标记或伪造检索措辞，逐条确认后再决定是否交付 |

**常见误报**：报告与检索缓存不同步（先跑检索、后手动改过文献表）时，
新增记录的 DOI 不在旧缓存里 → 退出码 1。此时把最新文献表一起传给 `--refs` 再核。

## 环境类

| 症状 | 处理 |
|---|---|
| `未找到项目，请设 ARA_HOME` | `export ARA_HOME=/path/to/academic-research-agent` |
| 中文检索报 cnki-mcp 未初始化 | 提示用户先跑 `uv run cnki-mcp init`（浏览器内完成知网认证），本skill 不代做登录 |
| Windows 下找不到 `python` | 用 `.venv/Scripts/python.exe` 绝对路径 |
| 沙箱内 DNS 解析失败 | 检索走Agent 自带 WebSearch 注入，不用项目内 ddgs |

## 何时该停下问人

- 主题拆解明显不对（对象/条件解析错了）
- 中文剔除率超过一半
- 三源全失败且重试两次仍失败
- 用户要的是立项建议（超出本skill 职责，判断权在人）
